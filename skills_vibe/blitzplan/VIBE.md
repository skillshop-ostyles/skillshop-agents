# /blitzplan — Stop. Denk kurz nach. Dann bau.

## Was ist das?

Du willst coden. Ich will erst sicherstellen dass wir beide vom selben Feature reden. 3-5 Fragen, 2 Minuten, dann kannst du losschlagen. Kein "3 Auth-Flows in einer Codebase" mehr.

## Wie benutze ich es?

- `/blitzplan eine Buchungs-App mit Login` — ich checke das Design in 3 Fragen
- `/blitzplan quick` — Turbo-Modus, 3 Fragen fertig
- `/blitzplan full` — Ausführlich mit Nicht-Zielen + Constraints

## Was passiert?

```
Phase 0: Modus wählen
Phase 1: 3-5 Fragen (eine pro Antwort)
Phase 2: Design anzeigen → du stimmst zu oder änderst
Phase 3: Implementation-Plan → du startest
```

## Was passiert NICHT?

- Keine Dateien werden geschrieben
- Kein Code bevor du freigibst
- Keine Subagenten, keine Worktrees, kein TDD-Zwang

## Warum sollte ich das nutzen?

Weil "einfach losprompten" der Grund ist warum vibe-codebases nach 3 Monaten unwartbar sind. 2 Minuten Planung sparen dir 2 Wochen Refactoring.
