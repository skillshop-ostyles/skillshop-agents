# Error-Handling Overview - /errors-overview

Strategic taxonomy of how a project handles errors: catch types (log/rethrow/
swallow/recover/fallback), global handlers, error class hierarchy, clustered
weaknesses.

```bash
git clone https://github.com/skillshop-ostyles/skill-shop-agents.git
cp -r skill-shop-agents/skills/understanding/error-handling-overview ~/.claude/skills/
```

## Usage

```
/errors-overview                          # interactive
/errors-overview <dir>                    # scan project
```
