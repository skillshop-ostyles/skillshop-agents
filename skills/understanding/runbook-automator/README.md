# Runbook Automator — /runbook

Generates a structured deployment runbook from live project sources: docker-compose.yml, package.json, CI/CD config, Dockerfile, healthcheck endpoints, and README commands.

```bash
git clone https://github.com/skillshop-ostyles/skill-shop-agents.git
cp -r skill-shop-agents/skills/understanding/runbook-automator ~/.claude/skills/
```

## Usage

```
/runbook                           # interactive
/runbook <dir>                     # scan project
```
