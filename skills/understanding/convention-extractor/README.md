# Convention Extractor - /conventions

Extracts implicit coding conventions from code patterns. Quantifies consistency and surfaces deviations.

```bash
git clone https://github.com/skillshop-ostyles/skill-shop-agents.git
cp -r skill-shop-agents/skills/understanding/convention-extractor ~/.claude/skills/
```

## Usage

```
/conventions                            # interactive
/conventions <dir>                      # scan project
```
