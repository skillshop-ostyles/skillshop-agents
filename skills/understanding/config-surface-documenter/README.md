# Config Surface Documenter - /config-docs

Generates a human-readable configuration reference from code: env vars, config files, CLI flags.

```bash
git clone https://github.com/skillshop-ostyles/skill-shop-agents.git
cp -r skill-shop-agents/skills/understanding/config-surface-documenter ~/.claude/skills/
```

## Usage

```
/config-docs                            # interactive
/config-docs <dir>                      # scan project
```
