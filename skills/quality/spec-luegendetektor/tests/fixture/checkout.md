# Checkout Flow

Der Checkout-Prozess muss schnell und benutzerfreundlich sein.

Ein Rabattcode kann nur EINMAL pro Bestellung angewendet werden – die Kombination
mehrerer Rabattcodes ist nicht vorgesehen.

Wenn die Zahlung fehlschlägt, zeigt das System eine Fehlermeldung und der Warenkorb
bleibt für den nächsten Versuch erhalten.

Nach erfolgreicher Zahlung wird eine Bestellbestätigung per E-Mail verschickt.
